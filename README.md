# SOA Data Cleaning Project

This repository contains data-cleaning notebooks and outputs for multiple reporting domains. Each notebook focuses on cleaning and preparing datasets used in reporting and visualization.

## Project Overview
- Clean and standardize raw data inputs.
- Produce filtered datasets for analysis.
- Generate graphs and reporting artifacts.

## Workspace Structure
- data/ — raw input data files.
- data_filtered/ — cleaned and filtered outputs.
- graphs/ — generated charts grouped by domain:
  - cargo/
  - equipment-failure/
  - interruption/
  - workers/
- winning-reports/ — final reports and summaries.
- docs/ — supporting documentation.

## Notebooks
- data-cleaning-cargo.ipynb
- data-cleaning-equipment-failure.ipynb
- data-cleaning-interruption.ipynb
- data-cleaning-workers.ipynb

Each notebook loads data from data/, applies cleaning steps, and writes outputs to data_filtered/ and graphs/.

## Requirements
- Python 3.x
- Jupyter Notebook or JupyterLab
- Common data libraries (e.g., pandas, numpy, matplotlib)

## Usage
1. Open the relevant notebook for your domain.
2. Run the cells top-to-bottom to reproduce cleaned datasets and visualizations.
3. Review outputs in data_filtered/ and graphs/.

## Notes
- Keep raw data in data/ unchanged.
- Generated outputs can be safely regenerated by re-running notebooks.
